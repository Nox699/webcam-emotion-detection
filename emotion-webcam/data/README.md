# Personal data

Complete webcam recording sessions create `personal.csv` here. No personal
dataset is bundled. Rows contain two detector proxies, 900 HOG values, a posed
label, a session ID, a sample index, and capture time. No face images are saved.

Keep this face-derived information local. To restart collection, exit the app
and back up or rename personal.csv. To erase personal training information,
also delete models/personal.json and reports/personal/.
