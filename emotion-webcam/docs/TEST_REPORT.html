Windows launcher fix in 1.0.1

The Python version/bitness check previously passed inline code through Windows PowerShell. The reported Windows run stripped its string quotes and raised NameError: name P is not defined. Version 1.0.1 runs that check from scripts/check_runtime.py, and uses the same file for Python discovery. Six new regression tests cover supported versions, incorrect bitness, nonzero failure exits, a script filename with spaces, and elimination of inline Python code from the PowerShell launcher. These tests run here; actual Windows execution remains a local acceptance check.
